# Manual testing pipeline

## Sonic and the Black Knight

* Extract the CSB files (e.g. `SE_SRT3V_SN_E.csb`)
* Replace the sounds with another sound (e.g. HL crowbar sound)
* If needed/wanted, tweak the number of samples and the frequency in the corresponding `sound_element.json` files
* Patch the file by the extractewd folder (remember that this game doesn't like re-creation of the CSB files from scratch *(TODO check how recreation works and how can I improve it)*)
* Launch the game and see that sounds are changed and are not distorted.
